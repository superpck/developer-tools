Why this matters

  • • Private ranges (RFC 1918) never route on the public internet.
  • • Loopback (127.0.0.0/8) always refers to the local machine.
  • • Link-local (169.254.0.0/16) means DHCP failed (APIPA).
  • • CGNAT (100.64.0.0/10) is used by ISPs behind shared NAT.
  • • Documentation ranges are safe to use in examples/docs.
